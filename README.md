# Pocket Empire — playable prototype v0.1

## Run it
1. Extract the ZIP.
2. Open `index.html` in Chrome, Edge, Safari, or Firefox.
3. Play: buy upgrades, collect tips, handle events, and check that progress saves in the same browser.

## What is included
- Business upgrade economy and income-per-second loop
- Three upgrade types with scaling costs
- Empire levels and district names
- Random business-event bonus
- Daily bonus
- Capped offline earnings
- Local browser save
- Missions and cosmetic/ad-free purchase previews

## Not included yet
- Native iOS/Android packages
- Real ad network SDK or live rewarded ads
- Real App Store / Google Play billing
- Analytics, cloud save, privacy disclosures, app icon/splash screens, store listing
- Final art, sound, accessibility and device QA

The “Watch demo ad” and shop buttons are simulation-only. They do not display ads or charge money.
